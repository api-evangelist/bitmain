# Bitmain

> Bitmain Technologies designs and manufactures ASIC cryptocurrency-mining hardware (the Antminer line) and operates Antpool, one of the world's largest Bitcoin mining pools. Antpool exposes a public HTTP API for account operators to read balances, hashrate, worker statistics, payment history, and pool statistics. Requests are signed with an HMAC-SHA256 signature (userId + apiKey + nonce, keyed by the API secret) and rate-limited to 600 requests per 10 minutes.

## APIs

- [Antpool API Guide](https://www.antpool.com/userApiGuide): Read account balance, account/worker hashrate, worker lists, payment history, and pool statistics. POST, form-encoded, JSON responses. Base URL https://antpool.com.
